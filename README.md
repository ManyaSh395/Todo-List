# Todo List Application
A modern, responsive Todo List application built with vanilla JavaScript, Webpack, and modular architecture.

This project was developed to demonstrate proficiency in:

Object-oriented programming (OOP)
ES6 modules
Webpack
DOM manipulation
Local Storage API
Separation of concerns

## Preview
The application features a clean and intuitive interface with:

1. A sidebar for managing projects
2. A main workspace displaying todos
3. Separate columns for In Progress and Completed tasks
4. Expandable todo cards with detailed information

## Features
### 📁 Project Management
Default project created automatically on first load
Create multiple custom projects
Switch between projects instantly
Optional project deletion support

### ✅ Todo Management
Each todo contains:

Title
Description
Due date
Priority (Low, Medium, High)
Completion status

Users can:

Add todos
Edit existing todos
Delete todos
Mark todos as completed
Expand cards to view full details

### 🎨 UI Features
Responsive layout
Sidebar navigation
Kanban-style columns
Priority color indicators
Modern card-based design
Smooth hover effects

### 💾 Data Persistence
All data is saved in localStorage
Projects and todos persist across page refreshes
Data is automatically loaded when the application starts

## How to run locally
1. Clone the Repository: 

git clone git@github.com:ManyaSh395/Todo-List.git

cd Todo-List

2. Install Dependencies: 

npm install

3. Start Development Server: 

npm run start

4. Open in Browser: 

http://localhost:8080/

5. Build for Production:

npm run build

Webpack generates optimized files inside the dist/ directory.
